# Сценарий демо HoneyForge

Показ на защите: **5–7 минут**, путь «ловушка → атака → живая лента → Юми →
расследование → IoC». Всё ниже проверено на локальном стенде 15.10.2026
(Windows + Docker Desktop, main после PR #46). Основной вариант — настоящий
центр и настоящая Low-ловушка; если стенд не поднимается — запасной вариант на
моках (раздел 5), он показывает весь интерфейс за 2 минуты подготовки.

## 1. Подготовка (за 30 минут до показа)

Команды — из корня репозитория `neiroleptik`. Нужны Docker Desktop, Node.js 22+,
Python 3.12 и `uv 0.11.28` (`python -m pip install --user uv==0.11.28`;
на Windows при ошибке установки Python задайте `UV_PYTHON_INSTALL_DIR` на
локальный диск, не OneDrive и не Roaming).

**Центр** (один раз; первый администратор создаётся интерактивно — README,
«Локальный запуск»):

```sh
docker compose --env-file .env -f infra/compose.center.yml up -d db
docker compose --env-file .env -f infra/compose.center.yml build api
docker compose --env-file .env -f infra/compose.center.yml run --rm api /app/.venv/bin/alembic upgrade head
docker compose --env-file .env -f infra/compose.center.yml up -d api
```

В Git Bash перед `run` задайте `MSYS_NO_PATHCONV=1`, иначе путь
`/app/.venv/bin/alembic` подменится путём Windows. Готовность:
`http://127.0.0.1:8000/readyz` → 200.

**Интерфейс на настоящем центре** (origin `127.0.0.1:5175` должен быть в
`HF_ALLOWED_ORIGINS`):

```sh
cd frontend
npm install
VITE_API_MOCK=0 VITE_EVENTS_ENABLED=1 VITE_INVESTIGATION_ENABLED=1 npx vite --host 127.0.0.1 --port 5175 --strictPort
```

В шапке должна быть метка «центр». Запись сессии, паспорт и сводка обзора на
сервере ещё не реализованы — их флаги не включаем.

**Образ Low и исполнитель:**

```sh
uv sync --frozen
docker build -f honeypots/low/Dockerfile -t honeyforge-low:local .
```

Регистрация узла: войти как `admin` → «Парк» → «+ Добавить хост» → скопировать
токен (действует 15 минут, показывается один раз). Каталог состояния агента —
на локальном диске, вне OneDrive. В том же терминале:

```sh
HF_ENROLLMENT_TOKEN='<токен из окна>' uv run --frozen python -m agent.runtime.executor.enroll \
  --center http://127.0.0.1:8000 --allow-http-loopback --name demo-low \
  --token-file <каталог агента>/agent.token
uv run --frozen python -m agent.runtime.executor --center http://127.0.0.1:8000 --allow-http-loopback \
  --token-file <каталог агента>/agent.token \
  --state <каталог агента>/executor/state.sqlite3 \
  --journal-root <каталог агента>/low \
  --image honeyforge-low:local --bind-address 127.0.0.1 --telemetry
```

`--telemetry` — исполнитель сам собирает журнал Low и отправляет события в
центр, ручные collect/deliver не нужны. Токен не вставлять в командную строку
постоянно и не показывать на экране.

**Перед показом проверить:**

- [ ] «Парк»: хост `demo-low` — «на связи».
- [ ] Старые хосты без связи отозваны («Отозвать»), чтобы не отвлекали.
- [ ] Низкоуровневый профиль (Low) есть в «Профилях».
- [ ] Окно браузера широкое (≥ 1280 px) — иначе окно Юми скрыто.
- [ ] Звук не нужен: Юми говорит текстом в консоли под листом.
- [ ] Открыт терминал с командами атаки (раздел 3), шрифт крупный.

## 3. Команды атаки

Порты ловушки назначает исполнитель; узнать:

```sh
docker ps --filter "name=honeyforge-low" --format "{{.Ports}}"
```

Пример вывода: `127.0.0.1:12323->2222/tcp, 127.0.0.1:18080->8080/tcp`.
Подставить HTTP-порт (`18080`) и TCP-порт (`12323`):

```sh
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:18080/
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:18080/admin
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:18080/.env
curl -s -o /dev/null -w "%{http_code}\n" -X POST -d "user=admin&pass=admin123" http://127.0.0.1:18080/login
printf 'hello honeypot\r\n' | timeout 5 bash -c 'cat > /dev/tcp/127.0.0.1/12323'
```

События появляются в ленте через несколько секунд (исполнитель собирает журнал
проходами). Источник — адрес Docker NAT (`172.17.0.1`), а не реальный IP: на
Docker Desktop внешний адрес не виден, это ожидаемо и стоит проговорить.

## 4. Что честно сказать о готовности

- **Работает на настоящих данных:** профили и ревизии, парк, регистрация и
  отзыв хостов, команды с подтверждением агентом, живая лента событий Low
  (HTTP и TCP), Юми, расследование (алерты, артефакты, медовые токены — по мере
  появления данных), экспорт IoC, аудит, роли.
- **Пока на моках / не реализовано на сервере:** запись сессии (replay),
  паспорт сессии и timeline, сводка обзора. Интерфейс для них готов и
  показывается в запасном варианте.
- **Не готово:** Medium (Cowrie) и High-ловушки; Low HTTP не пишет попытки входа,
  поэтому алерт о переборе на живом стенде не возникает.

## 5. Запасной вариант: демо на моках

Если центр или Docker не поднимаются — весь интерфейс на вымышленных данных:

```sh
cd frontend
npm install
VITE_API_MOCK=1 npx vite --port 5176
```

Входы: `operator`/`operator`, `admin`/`admin`, `viewer`/`viewer`. В шапке —
«демо-данные», в заголовке вкладки «[демо]» — проговорить, что это моки.
Показать то, чего ещё нет на сервере: каждые несколько секунд по WebSocket
приходит демо-атака (Юми реагирует), «Запись» у события открывает проигрыватель
сессии (пуск, скорость, перемотка; управляющие последовательности и ссылки
из вывода атакующего не исполняются), «Расследование» с алертом, медовым
токеном, артефактами и основанием по исходным событиям, роль наблюдателя без
кнопок изменения.

## 6. Если что-то пошло не так

| Симптом | Причина и действие |
|---|---|
| Хост «нет связи» | Исполнитель не запущен или упал — перезапустить командой из раздела 1 |
| «Запустить: истёк срок» | Команда ушла на хост без исполнителя — выбрать хост на связи |
| Лента «нет потока» | Не включён `VITE_EVENTS_ENABLED=1` или API без WebSocket — перезапустить фронт с флагом |
| Событий нет после атаки | Подождать 5–10 с; в выводе исполнителя должно быть `delivered:N` |
| Нет пиксельного шрифта | Старый main: подтянуть main (шрифты лежат в репозитории с PR #37) |
| Окно Юми не видно | Узкое окно браузера (< 1280 px) или нет WebGL — расширить окно; без WebGL Юми говорит в консоли |
| Всё сломалось | Переключиться на запасной вариант (раздел 5) |
